# MANGO

**MANGO** is a dataset and Python toolkit for the global analysis of Earth's magnetosphere.
Unlike raw satellite observations, MANGO provides a **unified, classified, and spatially normalized**
view of geospace, where each datapoint is contextualized by its magnetospheric region and upstream
solar wind conditions and repositioned relative to dynamic boundaries like the magnetopause and bow shock.
